# Combatetickets.mx — Launch Page

Landing estática de una sola pantalla para la etapa de pre-lanzamiento de Combatetickets.mx.

## Publicación

La página usa `index.html` y una sola imagen `landing.png`.

El único elemento interactivo es el enlace sobre el icono de Instagram, que apunta a:

https://www.instagram.com/combatetickets.mx/

## GitHub Pages

1. Ve a **Settings → Pages**.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Selecciona `main` y carpeta `/ (root)`.
4. Guarda.
5. GitHub generará la URL de Pages para este repositorio.

## Dominio personalizado

Cuando la página de GitHub Pages esté funcionando, configura el dominio personalizado `combatetickets.mx` desde **Settings → Pages → Custom domain**.

No cambies todavía los DNS del dominio hasta confirmar que GitHub Pages muestra correctamente la landing.

## Archivo pendiente

Sube `landing.png` a la raíz del repositorio, junto a `index.html`.
